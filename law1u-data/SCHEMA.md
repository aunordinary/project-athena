# โครงข้อมูลของ “หนึ่งบท หน้าเดียว” (law1u)

เครื่อง: `cpa-tarot/law1u.js` + `law1u.css` + `law1u.html?s=<รหัสบท>` · ข้อมูลของบท: `cpa-tarot/law1u-data/<รหัสบท>.js` ซึ่งกำหนด `window.LAW1U = { … }`
ตัวอย่างที่ใช้งานได้จริง: `law1u-data/P02.js` (เปิด `law1u.html?s=P02`) · ต้นแบบหน้าตาและจังหวะ: `law1p-setup-unit.html`
เครื่องไม่มีเกณฑ์ทางกฎหมายของตัวเอง ทุกเกณฑ์ ตัวเลข และเลขมาตราอยู่ในไฟล์ข้อมูล

## จังหวะของหนึ่งช่อง (ผู้ก่อตั้งกำหนด)
คำถามของตัวละคร → **ตัวอย่างหนึ่งกรณีที่เล่าจบ** พร้อมภาพและปุ่มปรับค่า (เห็นพร้อมกัน ไม่มีปุ่ม “ลองเปลี่ยนเอง”) → เงื่อนไขเป็นข้อ ๆ ติ๊กเขียว/กากบาทแดง มีเลขมาตรา → ผ่านครบแล้ว **เจอเรื่องใหม่ ลองตอบ** → แผ่นเล็กของอีกแบบ (ถ้าบทเทียบ บจก./บมจ.)

## ระดับบท
```js

  forms: true,                    // true = บทเทียบ บจก./บมจ. (มีปุ่มเลือกแบบ สีบานเย็น/น้ำเงิน แผ่นเล็กของอีกแบบ) · false = บทเดียวไม่แยกแบบ
  hue: ['#1F5D4C', '#E3F1EA', '#164437'],   // เมื่อ forms:false — สีสาย [เข้ม, อ่อน, ตัวหนังสือ]
  who: { ltd: 'พริ้ง', plc: 'พริ้ม' },      // ชื่อคนถามในฟองคำพูด (forms:false ใช้ { all: 'พริ้ง' })
  open: 'สองสามประโยค เล่าว่าเกิดอะไรขึ้น', // หน้าแรก

  mapQ: 'บทนี้ตอบสี่คำถาม', note: 'บรรทัดเล็กท้ายหน้าแรก (ไม่บังคับ)',

  table: { h: 'สรุปทั้งบท', rows: [['หัวแถว', 'บจก.', 'ป.พ.พ. ม.…', 'บมจ.', 'พ.ร.บ. ม.…']] },   // เฉพาะ forms:true
  keep: [['icon', 'ข้อควรจำหนึ่งบรรทัด', 'มาตรา (ไม่บังคับ)']],                              // ใช้แทน table เมื่อ forms:false
```

## หนึ่งช่อง
```js
{ id: 'vote', k: 'นับมติ', icon: 'vote',     // k = ป้ายใต้ไอคอน ไม่เกิน 2 คำ · id ห้ามขึ้นต้นด้วย _
  ltd: { …เนื้อหาของ บจก.… }, plc: { …ของ บมจ.… }   // หรือ all: { … } ถ้าช่องนี้ไม่แยกแบบ
}
```
เนื้อหาของช่อง (ทุกช่องใช้คีย์ชุดเดียวกัน ใส่เท่าที่ใช้)
| คีย์ | ความหมาย |
|---|---|
| `ask` | คำถามของตัวละคร หนึ่งบรรทัด เป็นคำที่คนพูดจริง |
| `h` | หัวการ์ด เป็นคำถามที่ช่องนี้ตอบ |
| `example` | ตัวอย่างหนึ่งกรณี เล่าจบในหนึ่งถึงสองประโยค บอกว่าตอนนี้ติดอะไร · ใช้ `{id}` แทนค่าตั้งต้นของตัวปรับได้ · หายเองเมื่อผู้เรียนเริ่มปรับค่า |
| `eq` | บรรทัดคำนวณที่อยากให้เห็นตลอด เช่น `'ทุน {cap} บาท ÷ 100 = {sh} หุ้น'` |
| `controls` | ตัวปรับค่า (ดูด้านล่าง) |
| `vars` | ค่าที่คำนวณจากตัวปรับ `{ ชื่อ: นิพจน์ }` |
| `body` | ลำดับของสิ่งที่อยู่ในการ์ด: `{ pic: {…} }` ภาพ · `{ ctl: 'id' }` ตัวปรับ · `{ p: 'ข้อความ', cls: 'small muted' }` |
| `checks` | เงื่อนไขที่ติ๊กได้: `{ text, law, when: นิพจน์, ok: 'ข้อความเมื่อผ่าน', no: 'ข้อความเมื่อยังไม่ผ่าน', hint: 'ทำอย่างไรให้ผ่าน' }` · **ทุกข้อต้องมี `law`** |
| `warns` | เรื่องที่ต้องรู้เพิ่มแต่ไม่ให้ลอง แถวสีเหลืองมี ! : `[['ข้อความ', 'มาตรา หรือ ""']]` |
| `solve` | ค่าของตัวปรับที่ทำให้ผ่านครบ (ปุ่ม “ดูเฉลย”): `{ id: ค่า }` |
| `sort` | กิจกรรมจับคู่: `{ q, bins: ['ก', 'ข'], items: [['ข้อความ', 0หรือ1]], done: 'ประโยคปิด' }` |
| `case` | เจอเรื่องใหม่ ลองตอบ: `{ f: 'เรื่องสองประโยค', q: 'ต้องแก้อะไร', o: [['ตัวเลือก', 0หรือ1, 'เหตุผล']] }` ถูกได้ข้อเดียว · ขึ้นหลังผ่านเงื่อนไขครบ |
| `mini` | สิ่งที่จะไปโผล่ในแผ่นเล็กเมื่อผู้เรียนดูอีกแบบอยู่: `[['ประโยคเดียว', 'มาตรา']]` · สองฝั่งต้องตอบคำถามเดียวกัน |

### ตัวปรับค่า (`controls`)
- ปุ่ม + / − : `{ id, type: 'step', label, unit, min, max, step, start }` (`max` เป็นนิพจน์ได้)
- สลับสองสถานะ : `{ id, type: 'toggle', on: 'ข้อความเมื่อจริง', off: 'ข้อความเมื่อเท็จ', start: false }`
- เลือกหนึ่งจากหลายอย่าง : `{ id, type: 'pick', label, options: ['ก', 'ข'], start: 0 }` หรือแบบการ์ดมีไอคอน `cards: true, options: [['icon', 'ข้อความ']]` ค่าคือลำดับที่เลือก

### นิพจน์
ตัวเลข · `true/false` · ชื่อตัวปรับหรือชื่อใน `vars` · หรือรายการ `['ตัวดำเนินการ', …]`
ตัวดำเนินการ: `+ - * /` · `>= <= > < == !=` · `and or not` · `ceil floor min max` · `['if', เงื่อนไข, ค่าเมื่อจริง, ค่าเมื่อเท็จ]`
ตัวอย่าง: `['>=', 'thai', ['ceil', ['/', 'n', 2]]]`

### ภาพ (`pic`) — เลือกตามสิ่งที่คนสับสน ไม่ใช่ทุกเรื่องต้องมีปุ่มบวกลบ
| `t` | ใช้เมื่อ | คีย์ |
|---|---|---|
| `dots` | นับคน/ที่นั่ง | `total, on, fill?, mark?, legend: [ทึบ, วงแหวน, …], aria` |
| `blocks` | สัดส่วนจากร้อย (หุ้นที่จอง ฯลฯ) | `on, target?, own?, legend: [จองแล้ว, ยังต้องหา, ของกลุ่มพิเศษ, นอกเป้า], aria` (ค่าเป็น 0–100) |
| `bar` | ค่าเดียวเทียบเส้นขั้นต่ำ | `value, need, max, label, atMost?` |
| `house` | ครึ่งวงกลมแบบสภา: องค์ประชุม/มติ | `total, yes, no, mark?, markLabel, big?, sub, legend: [เห็นชอบ, ไม่เห็นชอบ], aria` |
| `timeline` | ลำดับเหตุการณ์ | `events: [{ k, d?, law?, dl?: 'ภายใน 3 เดือน' }], end: true` |
| `clock` | เส้นตายที่เลื่อนเวลาได้ | `clocks: [{ k, from, to, u: 'md'|'ym'|'d', lim, law, late?: 'ผลเมื่อเลยกำหนด', start }]` · `late` ใส่เฉพาะผลที่อ่านจากตัวบทแล้ว |
| `papers` | เอกสารที่แตะบรรทัดได้ | `papers: [{ k, sub, rows: [['บรรทัด', 'คำอธิบาย']] }]` |
| `roles` | สองบทบาทวางคู่ | `roles: [{ k, sub, icon, items: [['หน้าที่', 'มาตรา']] }]` |
| `zones` | สองกลุ่ม แตะตัวเลือกแล้วดูว่าตกกลุ่มไหน | `of: 'id ของ pick', zones: [{ k, d, law }], map: [กลุ่มของแต่ละตัวเลือก], says: [คำตอบของแต่ละตัวเลือก]` |
| `tips` | ข้อควรจำมีไอคอน | `items: [['icon', 'ข้อความ (ใช้ <b> ได้)', 'มาตรา?']]` |

ไอคอนที่มี: `hand shop tower people person share coin doc stamp pencil eye book scale lock flag list cal globe link vote seat bell gavel up swap check x`

## โจทย์ท้ายบท (`quiz`)
- เลือกข้อเดียว `{ t: 'one', f: 'ข้อเท็จจริง', q: 'คำถาม', o: [['ตัวเลือก', 0หรือ1, 'เหตุผล']] }`
- เลือกหลายข้อ `{ t: 'multi', f, q, o: [['ตัวเลือก', 0หรือ1]], ex: 'คำอธิบายเมื่อถูกครบ' }`
- พิมพ์ตัวเลข `{ t: 'num', f, q, a: 7501, u: 'หุ้น', ex, hint }`
ใช้โจทย์จากคลังเดิมของบท เฉลยห้ามเปลี่ยน ถ้อยคำเขียนให้สั้นได้ โจทย์แบบเรียงลำดับให้แปลงเป็นเลือกข้อเดียวที่ถามลำดับ

## กติกาที่ไฟล์ข้อมูลต้องผ่าน
1. ทุก `checks[].law` ทุกการ์ดกฎ และทุกแถวของ `table` มีชื่อกฎหมายและเลขมาตรา · เลขมาตราทุกตัวต้องมีอยู่ในบทเดิมที่ตรวจแล้ว (`cpa-tarot/law1p-data/<บท>.js`) หรือในสำเนาตัวบท (`…/evidence/<บท>/`) — ตัวตรวจ `check_law1u.py` จะตีกลับเลขที่หาไม่เจอ
2. ห้ามสร้างเกณฑ์ขึ้นเองเพื่อให้ภาพขยับได้ ถ้ากฎหมายไม่มีตัวเลข ให้ใช้ภาพที่ไม่ต้องมีเส้นเกณฑ์
3. ผลทางกฎหมาย (เลยกำหนดแล้วเกิดอะไร ฯลฯ) ใส่ได้เฉพาะที่อ่านจากตัวบท จุดที่ไม่แน่ใจให้เว้น แล้วจดไว้ในรายการ “ไม่แน่ใจ” ที่ส่งมาพร้อมไฟล์
4. ภาษา: คำที่คนพูดจริง ประโยคสั้น ใจความมาก่อนเลขมาตรา · ไม่ใช้คำว่า แฟ้ม แม่บท ด่าน เคส ชั้น (ในความหมายของคนทำบท) · หลังตอบใช้ “ถูกใจใช่เลย / อาจจะยัง” (เครื่องใส่ให้เอง ไม่ต้องพิมพ์ในข้อมูล)
5. ไม่มีคะแนน ไม่มีคำว่าผ่าน/ตกทั้งบท
6. เขียนชื่อกฎหมายและเลขมาตราเป็นข้อความเต็มทุกที่ (เช่น `'ป.พ.พ. มาตรา 1107'`) ไม่ต่อสตริงจากตัวแปร เพื่อให้ตัวตรวจอ่านเลขมาตราได้ครบ (ไฟล์ P02 เขียนไว้ก่อนมีกติกานี้)
7. ไฟล์ต้องเป็น JavaScript ที่โหลดได้เลย: ขึ้นต้น `window.LAW1U = {` ปิดด้วย `};` ใช้อัญประกาศเดี่ยว ข้อความที่มี ' ให้ใช้ \' · ตรวจด้วย `python3 exchange/v2/builds/law1p-independent-ui-review-2026-10-04/hero-setup-demo/check_law1u.py <บท>`

## เพิ่มรอบ 16 (10 ต.ค. 2569)
- บทที่ไม่มีสองแบบ: ไม่ใส่ `forms` ทุกช่องใช้ `all` · ตั้งสีสายด้วย `hue: [สีหลัก, สีอ่อน, สีตัวหนังสือ]` · `who: { all: 'ชื่อ' }`
- `table.cols: ['', 'หัว 1', 'หัว 2', …]` ตั้งหัวคอลัมน์เอง (ไม่ใส่ = บจก./บมจ.) · แถว `[หัวแถว, ค่า, หมายเหตุ, ค่า, หมายเหตุ, …]`
- ช่องที่มีเฉพาะ `ltd` หรือเฉพาะ `plc` จะไม่ขึ้นบนแถบเมื่อผู้เรียนเลือกอีกแบบ
- ภาพ `clock`: ค่าเริ่มต้นประโยคคือ “ต้อง<to>ภายใน N” (หน้าที่) · ถ้าเป็นสิทธิหรือช่วงที่ทำได้ ใส่ `may: true` จะเป็น “<to>ได้ภายใน N” · หรือเขียนเองทั้งประโยคด้วย `within: '…'` (ตอนยังทัน) และ `over: '…'` (ตอนเลยกำหนด)
- โจทย์ท้ายบทของบทสองแบบ: ใส่ `ent: 'ltd'` หรือ `ent: 'plc'` ในข้อที่เป็นของแบบเดียว ผู้เรียนจะเห็นเฉพาะข้อของแบบที่เลือก (ไม่ใส่ = ขึ้นทั้งสองแบบ) แต่ละแบบควรมีอย่างน้อย 3 ข้อ
- รายการใน `body` ใส่ `if: นิพจน์` ได้ จะขึ้นเฉพาะเมื่อนิพจน์เป็นจริง เช่น `{ if: ['==', 'kind', 1], pic: {…} }` (ใช้เมื่อภาพหรือตัวปรับเกี่ยวกับบางตัวเลือกเท่านั้น)
- ช่องที่ “ครบทุกข้อ” ไม่ใช่ข่าวดีของตัวละคร (เช่น ครบแล้ว = ถูกยึดได้ / ต้องรับผิด): ตั้งคำสรุปเองด้วย `sumOk: '…'` `sumNo: 'ครบ {ok} จาก {all} ข้อ …'` และคำนำคำใบ้ด้วย `hintLabel: 'จะครบเมื่อ: '` (ไม่ใส่ = “ทำให้ผ่าน: ”)
- ภาพ `house` ที่ไม่ได้เป็นเรื่องลงคะแนน (เช่น สัดส่วนทุนของคนต่างด้าว) ใส่ `neutral: true` จะใช้สีประจำสายกับเทาอ่อน แทนเขียว/เทาเข้มของเห็นชอบ/ไม่เห็นชอบ
- `sort.items`: ใส่เหตุผลเป็นช่องที่สามได้ `[ข้อความ, กลุ่มที่ถูก, 'เหตุผลสั้น ๆ']` จะขึ้นเมื่อผู้เรียนเลือกผิด (ผู้ตรวจอิสระทักว่าตอบผิดแล้วได้แค่ ✕)
- ผู้ก่อตั้ง: **ไม่ใช้วันที่จริง** · **กฎหมายไม่พูดถึง ก็ไม่ต้องเอ่ยถึง** (ตัวตรวจตีกลับคำว่า “บทนี้อ่านว่า” “ยังไม่ตัดสิน” “ยังไม่พบ”)

## วันที่บนเส้นเวลา — **ไม่ใช้** (ผู้ก่อตั้งเปลี่ยนใจ 10 ต.ค. 2569 · เก็บไว้เป็นบันทึกของตัววาดเท่านั้น)
ใช้กับบทที่หัวใจคือ “อะไรก่อนหลัง” และ “ภายในกี่วัน” ตัวอย่างเต็ม: `P02-t.js`
- ระดับบท: `cal: { y: 2569, m: 10, d: 1 }` วันตั้งต้น (พ.ศ.) · `story: { ltd: [...], plc: [...] }` เส้นเวลาของทั้งเรื่อง ขึ้นที่หน้าแรกและท้ายบท แต่ละจุด `{ at, dl, k, d, law }` (`at` = วันที่ของเรื่อง · `dl` = กำหนดตามกฎหมาย) · `storyQ` `storyNote`
- วันที่ในนิพจน์: `['d', วัน, เดือน, ปี?]` · `['addm', วันที่, จำนวนเดือน]` · บวกลบวันใช้ `+` `-` ตามปกติ · ในข้อความใช้ `{d:ชื่อ}` จะออกเป็น “5 ต.ค.”
- ในช่อง: `time` ป้ายช่วงเวลาเหนือหัวข้อ (ข้อความ หรือ `{ ltd, plc }`) · `fixed: { ชื่อ: นิพจน์ }` วันที่ตายตัวของเรื่อง คิดก่อนตัวปรับ
- ตัวปรับ `type: 'date'`: `min` `max` `start` เป็นนิพจน์วันที่ · `months: true` เพิ่มปุ่มเลื่อนทีละเดือน · `base: 'meet'` = เก็บเป็นระยะห่างจากวันนั้น (min/max/start เป็นจำนวนวัน เช่น -10) วันที่จะเลื่อนตามเมื่อ base ขยับ

- ภาพ `span` เส้นเวลาหลายเดือน: `from` `to` · `marks` แบบเดียวกัน · `deads: [{ at, k }]`
- ภาพ `timeline` รับ `at` และ `{d:…}` ใน `k` `d` `dl` ได้ จึงขยับตามตัวปรับ
- โจทย์เรียงก่อนหลัง: `{ t: 'order', f, q, items: [เขียนตามลำดับที่ถูก], show: [ลำดับที่วางบนจอ], done }` ใช้ได้ทั้งใน `quiz` และเป็น `case` ของช่อง

```js
  { at: 500, k: 'เส้นแรก', tone: 'gold' }, { at: 1000, k: 'เส้นที่สอง' }, { at: 10000, k: 'เส้นที่สาม', tone: 'bad' }] } }
```
หมุดกับแถบแสดงค่าปัจจุบัน ใต้ไม้บรรทัดบอกเป็นคำว่าอยู่ช่วงไหน (“ยังไม่ถึงเส้น … / อยู่บนเส้น … พอดี / อยู่ระหว่างเส้น … กับเส้น … / เลยเส้น … แล้ว”) — เป็นคำบอกตำแหน่งเท่านั้น ผลทางกฎหมายของแต่ละช่วงให้เขียนเองด้วย `says: ['ช่วงก่อนเส้นแรก', 'ช่วงถัดไป', …]` (จำนวน = เส้น + 1 · รับ `{ตัวแปร}`) หรือใน `checks` · ตั้งแต่สองเส้นขึ้นไป **ช่องระหว่างเส้นกว้างเท่ากัน** (ไม่ตามสัดส่วนจริง เครื่องเขียนกำกับให้) ถ้าต้องการสเกลตรงใส่ `linear: true` · `min` ไม่ใส่ = 0
ชนิด `bar` เดิมรับ `marks: [{ at, k, tone }]` (และ `unit`) เพิ่มเส้นได้หลายเส้นบนสเกลตรงของแถบเดิม ไม่ใส่ = แถบเดิมทุกอย่าง

### 5. `cal` — ปฏิทินช่วงวัน (เลขลำดับวัน ไม่ใช่วันที่จริง)
```js
{ pic: { t: 'cal', from: 1, to: 20, day: 'day', due: 7, label: 'เดือนถัดจากเดือนที่จ่าย', dayK: 'วันที่ยื่น', dueK: 'วันสุดท้าย' } }
```
วันครบกำหนดมีกรอบ วันที่เลือกเป็นจุด วันหลังกำหนดเป็นลายขีดโทนเตือน ข้อความผล “ทัน เหลืออีก … วัน / ทัน วันครบกำหนดพอดี / เลยมา … วัน” · เครื่องถือว่าเลยเมื่อ `day > due` ถ้าบทต้องตัดสินเอง (เช่น วันหยุด) ใส่ `late: นิพจน์` · เขียนข้อความเองได้ด้วย `okSay` `lateSay` (ใช้ `{_left}` `{_over}` = จำนวนวันที่เหลือ/เลย) · `cols` = จำนวนช่องต่อแถว (ไม่ใส่ = 7) · ต่างจาก `days` เดิมตรงที่ไม่ผูกกับปฏิทินจริง จึงใช้ได้กับกติกา “ไม่ใช้วันที่จริง”

### 6. `ledger` — ตารางสมุด (วางรายการลงสมุดทีละแถว)
```js
{ pic: { t: 'ledger', aria: 'สมุดเงินสด', cols: ['วันที่', 'รายการ', 'รับ', 'จ่าย'], empty: 'ยังไม่มีรายการ', rows: [
  { cells: ['1', 'ขายสินค้า', '5,000', ''], show: 'r1', tone: 'good' }, { cells: ['2', 'ซื้อของ', '', '{buy}'], show: 'r2' }],
  foot: ['', 'คงเหลือ', '{bal}', ''] } }
```
แถวโผล่เมื่อ `show` เป็นจริง (ไม่ใส่ = ขึ้นเสมอ) · ช่องที่เป็นตัวเลขล้วนชิดขวาให้เอง · เกินสามช่องบนจอแคบ ตารางเลื่อนซ้ายขวาในกรอบของตัวเอง หน้าไม่ล้น

### 7. `grow` — ก้อนที่โตตามเวลา
```js
{ pic: { t: 'grow', unit: 'บาท', label: 'ยอดที่ต้องนำส่ง', max: 2000, base: { k: 'ภาษีที่ต้องนำส่ง', v: 1000 }, add: { k: 'เงินเพิ่ม {m} เดือน', v: 'addv' },
  extra: [{ k: 'ค่าปรับ', v: 200, show: ['>', 'm', 0] }] } }
```
แท่งซ้อน: ฐานคงที่ ส่วนเพิ่ม (ลายขีด) โตตามค่า ส่วน `extra` เป็นกล่องเส้นประแยกออกมา ยอดรวมตัวใหญ่ = ฐาน + ส่วนเพิ่ม + extra ที่ขึ้นอยู่ (ตั้งเองได้ด้วย `total`) · `max` = ค่าที่เต็มความสูงของแท่ง (ไม่ใส่ = สองเท่าของฐาน) · ต่างจาก `split` ที่แบ่งก้อนเดียวออกเป็นส่วน ๆ

### คำขอเพิ่มจากผู้เขียน (รอบเดียวกัน)
- **`split` ส่วนที่จาง:** `parts: [{ k, v, dim: นิพจน์ }]` — `dim` จริง = ส่วนนั้นยังวาดอยู่แต่จาง มีป้าย “ยังไม่นับ” (เปลี่ยนคำด้วย `dimSay` ของภาพ) จำนวนเงินขีดฆ่า ใช้กับบิลหลายท่อนที่ผู้เรียนเลือกว่าท่อนไหนนับ: ให้ `v` เป็นจำนวนเต็มของท่อนเสมอ แล้วให้ `total` เป็นยอดที่นับ เช่น `{ k: 'ค่าแรง', v: 2000, dim: ['not', 'lab'] }` (ไม่ใส่ `dim` ที่ส่วนใดเลย = แถบเดิม)
- **กลุ่มตัวปรับ** ใน `body` (ใช้แทน `{ ctl }` หลายบรรทัดติดกัน): `{ ctls: ['lab', 'part', 'vat'], title?: 'หัวกลุ่ม', hint?: 'คำบอกวิธีแตะ' }` ปุ่ม toggle ในกลุ่มไม่ต่อท้าย “(แตะเพื่อเปลี่ยน)” เครื่องบอกครั้งเดียวเหนือกลุ่ม
  - `as: 'check'` = แถวมีช่องติ๊ก · `as: 'bill'` = กระดาษบิล: หัวกระดาษ (`title` `sub`) + แถวรายการ (ช่องติ๊กซ้าย ชื่อรายการ จำนวนเงินชิดขวา) + แถวรวม
    ```js
    controls: [{ id: 'lab', type: 'toggle', k: 'ค่าแรง', amt: 2000, start: false }, { id: 'part', type: 'toggle', k: 'ค่าอะไหล่', amt: 8000, start: false }, { id: 'vat', type: 'toggle', k: 'ภาษีมูลค่าเพิ่ม', amt: 700, start: false }],
    vars: { base: ['+', ['+', ['if', 'lab', 2000, 0], ['if', 'part', 8000, 0]], ['if', 'vat', 700, 0]] },
    body: [{ ctls: ['lab', 'part', 'vat'], as: 'bill', title: 'ใบแจ้งค่าซ่อม', sub: 'บริษัท พร้อมซ่อม จำกัด', unit: 'บาท', total: { k: 'ยอดที่นับ', v: 'base' } }]
    ```
    `k` = ชื่อรายการ · `amt` = จำนวนเงิน (นิพจน์ได้) · `on` `off` ถ้าใส่จะเป็นบรรทัดเล็กใต้ชื่อ (ไม่มี `k` = ใช้ `on`/`off` เป็นชื่อแถว) · `hint` เปลี่ยนคำบอกวิธีแตะ
  - toggle ตัวเดียวที่อยากได้ช่องติ๊ก: ใส่ `as: 'check'` ที่ตัวปรับ แล้วใช้ `{ ctl: 'id' }` ตามเดิม · `quiet: true` ที่ตัวปรับ = ปุ่มเดิมแต่ไม่ต่อท้าย “(แตะเพื่อเปลี่ยน)”
- **`papers` วางคู่บนจอแคบ:** `pair: true` สองใบวางคู่กันที่ 375 (ตัวหนังสือ 13px) ใช้เมื่อแต่ละบรรทัดสั้น · **ส่งบรรทัดที่แตะออกเป็นตัวแปร:** `out: 'tap'` → `tap` = ลำดับบรรทัดนับต่อกันทุกใบ เริ่ม 0 (ยังไม่แตะ = -1) · `tap_p` = ใบที่ · `tap_r` = บรรทัดที่ในใบนั้น ใช้ได้ใน `vars` `checks` `if` และ `{tap}` (ภาพ papers ที่ใส่ `out` ถือว่าการแตะเป็นการปรับค่า กล่องตัวอย่างจะย่อ)
- **`sort` สามกล่อง:** `bins` สามชื่อเรียงสามคอลัมน์เท่ากัน บนจอแคบ (≤440) เรียงลงทั้งสาม เครื่องทำให้เอง

### ของที่เครื่องทำให้เองตั้งแต่รอบนี้ (ไม่ต้องเขียนอะไรในข้อมูล)
- **ทายก่อนแตะ:** ตัวปรับ `pick` ที่ตั้ง `start: -1` เริ่มโดยไม่เลือกอะไร และภาพ `zones` ที่ผูกกับมันจะยังไม่เฉลย (ขึ้นบรรทัดชวนทาย เปลี่ยนคำได้ด้วย `wait: '…'` ของภาพ) — ช่องที่เขียน “ทายในใจก่อนแตะ” ควรใช้ `start: -1` · ภาพอื่นที่อ่านค่าจากตัวเลือกนั้นให้ใส่ `if: ['>=', 'id', 0]`
- **ดูเฉลย:** `solve` รับนิพจน์ จึงเขียน `solve: { held: 'need' }` ได้ ไม่ต้องตรึงตัวเลือกอื่น (ถ้าใส่ `inst: 0` ไว้ ปุ่มจะพากลับตัวเลือกแรกตามที่เขียน) · กดแล้วจออยู่ที่เดิม ไม่เด้งขึ้นบนสุด
- จอไม่กระโดดเมื่อกล่องตัวอย่างย่อ · “เจอเรื่องใหม่” โผล่ครั้งแรกจะถูกเลื่อนขึ้นมาให้เห็นหัว · คำอธิบายหลังตอบไม่ซ่อนใต้แถบปุ่มล่าง
- ตัวเลขกับ `บาท คน วัน เดือน ปี ชั่วโมง หุ้น` และ `มาตรา/ข้อ/ร้อยละ` กับตัวเลข ไม่แยกบรรทัด (เครื่องแทนช่องว่างด้วย U+00A0 ตอนแสดงผล **ข้อความบนจอจึงมี U+00A0** ตัวตรวจที่เทียบข้อความจากจอต้องเทียบแบบไม่สนชนิดช่องว่าง)
- คำที่ห้ามหักกลาง: เครื่องมีรายการกลาง (คำสั่ง มาตรา รายละเอียด ร้อยละ นิติบุคคล ฯลฯ) + ชื่อใน `who` · บทเพิ่มคำของตัวเองได้ด้วย `nobreak: ['พาวเด้ออ้าย', 'ชื่อร้าน']` ที่ระดับบท (คำละไม่เกินราว 12 ตัวอักษร)
- ป้ายกฎหมายยาวเกิน 60 ตัวอักษรแสดงแบบย่อ “… ดูเต็ม” แตะเพื่อขยาย (ข้อความเต็มอยู่ใน DOM เสมอ)
- ท้ายบทมีบรรทัด “ลองตอบครบทุกข้อ บทนี้จะนับว่าเรียนครบ” · นับเมื่อกดตอบหนึ่งครั้งต่อข้อ ไม่ต้องถูก และจำไว้ถาวร

- `ruler` เพิ่มสองตัวเลือก (ค่ำ 11 ต.ค. 2569): `markUnit: true` ต่อหน่วยท้ายเลขบนเส้น (เช่น “60 เดือน”) · `fade: true` แถบช่วงก่อนหมุดจางและเป็นลายขีด ใช้เมื่อช่วงก่อนหมุดคือสิ่งที่ยังไม่นับ

## เพิ่ม 12 ต.ค. 2569 — โหมดกดตรวจ (ใช้กับสาย CIT ของกฎหมาย 2)

ระดับบท (ไม่ใส่ = พฤติกรรมเดิม):
- `check: true` — คำถามเลือกตอบข้อเดียวทั้งบท (`case` ของช่อง และ `quiz` ท้ายบท): แตะ = เลือก ยังไม่เฉลย · ปุ่ม «ตรวจคำตอบ» · หลังตรวจมีแผง «ดูเหตุผลทุกตัวเลือก» และปุ่ม «ตอบใหม่» · เลือกข้ออื่นหลังตรวจ ผลเดิมหาย · นับว่าลองแล้วเมื่อกดตรวจ
- `rev: 'ข้อความรุ่น'` — เปลี่ยนค่านี้เมื่อแก้โจทย์หรือตัวเลือก สถานะที่ผู้เรียนเก็บไว้ของรุ่นเก่าจะถูกข้าม บทเริ่มใหม่
- `words: { ok: 'คำนำเมื่อถูก', no: 'คำนำเมื่อยังไม่ถูก' }` — แทน “ถูกใจใช่เลย” / “อาจจะยัง” ของข้อเลือกตอบข้อเดียว · `''` = ไม่มีคำนำ

ทุกบท: ปุ่ม «เริ่มบทนี้ใหม่» ต้องกดสองครั้ง · ผลของโจทย์ตัวเลขหายเมื่อแก้ตัวเลขหลังตรวจ · คำตอบที่เก็บไว้ไม่ตรงกับโจทย์ปัจจุบันถือว่ายังไม่ตอบ
